# DR--20251113--config--config-governance
⚙️ DR: Configuration governance — single config file under ~/.config/securelocal

Context
Environment variables and configuration drift cause errors in automated scripts.

Decision
Centralise configuration in ~/.config/securelocal/config.env, generated by the installer.
Scripts source this file at runtime and validate all required variables.

Consequences
	•	One canonical source of truth.
	•	Simple to back up, inspect, or recreate.
	•	Prevents silent misconfiguration.
	•	Changes require reinstall or manual edit (by design).

Notes
Future enhancements might include per-environment overrides or schema validation.
